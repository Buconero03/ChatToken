# Context Guardian v1.3.0 — Cross-browser packages

All download options are assets of **this single release**:

- **CHROMIUM.zip** — Chrome, Edge, Brave, Opera and Vivaldi (unpacked extension)
- **FIREFOX.zip** — Mozilla Firefox (temporary add-on; public signing still required)
- **SAFARI.zip** — Safari source files (requires macOS/Xcode packaging)

The shared BPE engine is identical in all three builds. The operational checkpoint is 240,000 historical text tokens against a reference of 250,000. It does **not** measure ChatGPT's internal active-context saturation.

Install instructions are in `README.md` and `INSTALLAZIONE_IT.md`.
